# Simple Timekeeper WebApp

This is a simple app for timekeeping, that can be used if you want to have a simple way to check-in/-out and view the logged times.
The tech stack:
  Frontend:
    GitHub Pages
    JavaScript
  Backend:
    Free Supabase + DB in PostgreSQL

# Dev:
Install the requirements_python.txt to have a live server to have check on the cookies (they won't be created if the html runs locally).

After installation just run:
python3 dev_server.py
(maybe even just python without the 3 depending on your python versions installed)

Important note:
You need to be in the same directory as the script with your terminal/ CLI, as the path to the index.html etc. (docs-folder) is relative to 
the terminal/ CLI and NOT to the script itself.
